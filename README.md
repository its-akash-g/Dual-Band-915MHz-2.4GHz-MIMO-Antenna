# 915 MHz & 2.4 GHz Dual-Band Quad-Port MIMO Antenna Array

This repository contains the IEEE-formatted LaTeX source code, figures, and documentation for a **915 MHz and 2.4 GHz dual-band quad-port MIMO antenna array**.

## 📌 Project Overview
* **Operating Frequencies:** 915 MHz (sub-GHz ISM band) & 2.4 GHz (WLAN)
* **Decoupling Mechanism:** Central ring resonator with 4 bent defected ground surface (DGS) branches
* **Port Isolation:** > 20 dB across both operational bands
* **Peak Gains:** 0.5 dB at 915 MHz | 3.23 dBi at 2.4 GHz
